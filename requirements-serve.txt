# Serving-only dependencies for app.py / the Docker image.
#
# Deliberately much smaller than requirements.txt. Training and evaluation need
# scikit-learn, scikit-image, pandas, matplotlib and seaborn; serving a single
# image needs none of them. app.py imports build_model and build_eval_transform
# from evaluate.py, and evaluate.py imports sklearn lazily *inside* functions
# rather than at module scope -- so the import chain stays light. Dropping those
# packages removes roughly 400 MB from the image.
#
# torch here is the CPU build (~200 MB vs ~2.6 GB for CUDA). Serving one image
# at a time gains nothing from a GPU. Installed from PyTorch's CPU index in the
# Dockerfile, not from PyPI.
